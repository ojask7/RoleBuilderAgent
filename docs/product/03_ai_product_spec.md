# AI Product Spec

## Problem
Identity teams spend weeks reconciling IAM security groups with authoritative applications and completing KC27 reviews. Data is fragmented across AD, SailPoint, and CMDB, causing manual spreadsheets and audit gaps.

## Target Users
- Chief Information Security Officer
- IAM Engineer / Role Mining Specialist
- Application Owner / Service Manager

## MVP Scope
1. Host SG→AS/BA mapping agent with explainable reasoning and owner suggestions.
2. Provide KC27 verification agent with contextual evidence (RAG) and decision logging.
3. Ship REST APIs, sample prompts, and runbooks so teams can integrate with existing workflows.
